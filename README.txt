IPHONE WEB APP
Upload index.html + manifest.json to an HTTPS static host.
Open in Safari -> Share -> Add to Home Screen.

SAVED DAILY DATA
Every date gets its own local record for:
- WHOOP Recovery, HRV, RHR, sleep performance, sleep duration, sleep debt, strain, WHOOP calories
- Weight and optional waist
- Every meal, calories and protein
- Water cups
- Daily checklist

PROGRESS TAB
Shows a daily history table containing all these inputs plus a weight trend.
WHOOP inputs influence the daily training recommendation and starting calorie target.
