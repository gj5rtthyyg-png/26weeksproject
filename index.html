WHOOP intensity rules

  • Recovery ≥67%: planned training, normal loads.
  • 34–66%: reduce volume/intensity ~20% if needed.
  • ≤33%: walking/mobility or easy Zone 2; no HIIT/heavy lifting.

Weekly review

Adjustment rule

Use the 14–21 day weight trend. If loss is ~0.4–0.8 kg/week, keep the plan. If there is no meaningful loss for 2–3 weeks with good adherence, reduce ~100–150 kcal/day or add ~1,500–2,000 steps/day. If loss is consistently >0.9 kg/week with poor energy/training, increase intake slightly.
